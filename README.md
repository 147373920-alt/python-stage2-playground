# Python 第二阶段 · 闯关学习台

一个**纯静态、单文件**的 Python 学习台：打开浏览器就能写代码、跑代码、自动判题、画出动画。不用安装 Python，不用服务器，不需要联网运行代码（只有首次加载引擎需要联网）。

面向 8–12 岁、已经学完 Python 第一阶段（变量、字符串、列表、分支）的孩子，覆盖 6 个单元、约 6 个月的内容。
内容结构对齐「数据处理 → 多数据结构 → 循环枚举 → 二维列表 → 函数 → 游戏开发」这条常见路线，可以按自己的课程替换。

## 它解决什么问题

给孩子用的编程练习平台，通常卡在三个地方：

1. **要装环境**：装 Python、配环境变量，家长先崩一轮
2. **只有练习场，没有路线**：打开一片空白，孩子不知道今天学什么
3. **跑通了不等于学会了**：没有任何验收，孩子点个运行看到输出就以为会了

这个学习台针对这三点：

- **零安装**：一个 HTML 文件，双击就能用，可以放 U 盘、可以挂任何静态托管
- **有路线**：6 个单元 30 个条目，课文 → 练习 → 交付物 → 实验室，一条线走完
- **有验收**：每道练习有判题数据，输出逐行比对，错了给左右对照；每个单元有「交付物」（能演示才算过）
- **有讲解**：每节课有生活化比喻、逐行代码讲解、改坏也不怕的「试一试」

## 技术实现

**Python 是真的在跑**，不是模拟：用 [Pyodide](https://pyodide.org)（CPython 编译成 WebAssembly）在页面内执行。`input()` 由页面的输入框按行供给，所以每道练习都能跑真实的输入输出。

**判题**就是把输出与期望输出逐行比对（忽略行尾空白），失败时左右并列显示，一眼能看出少了一行还是空格不对。

**动画实验室**采用「先录分镜、再逐帧播放」的方式：Python 里的中文命令（`前进`、`右转`、`画方块`、`写字`）先把操作录进帧序列，代码跑完再逐帧画到 canvas 上。这样避开了 Python 调用 JS 异步函数不会等待的问题，也顺带解决了死循环卡死页面——帧数或步数超限会主动中断并提示。

**进度存在浏览器本地**（localStorage），不联网、不上传，换设备不同步。

## 怎么用

1. 下载 `index.html`
2. 双击，用 Chrome / Edge 打开（Safari 也可以）
3. 首次点「运行」会加载 Python 引擎，约 20–60 秒，需要联网；之后一直就绪
4. 从左侧导航选一课开始

建议节奏：**一周一课一练**，先做当月交付物，再进实验室玩。判题通过不代表学会，还要能讲清每行代码在干什么。

## 怎么改成你自己的课程

所有内容都是 `index.html` 里的 `UNITS` 数组，明文、无构建步骤。一个条目大概长这样：

```js
{type:"lesson", id:"L7-1", title:"让程序开口说话：input 与 print",
 intro:["要点一","要点二"],
 analogy:"打个比方……",
 lineNotes:[["代码行","这行在干什么"]],
 tryThis:["改动挑战一"],
 example:{input:"输入示例", code:`示例代码`},
 tip:"提示"}

{type:"exercise", id:"E1", deliver:true, title:"练习：成绩统计器",
 task:["题目要求"],
 steps:["解题路线图"],       // 给顺序，不给答案
 input:"78\n92\n45\n",       // 判题用的输入
 expected:`期望输出`,         // 判题比对的标准输出
 starter:`起始代码模板`,
 answer:`参考答案`}
```

改这四样就能换成一门新课程：`title`、`task`、`input`、`expected`。改完记得用参考答案跑一遍，确认输出和 `expected` 完全一致。

## 已知边界

- **pygame 跑不了**（需要图形窗口）。Lv.12 用文字版练游戏逻辑，骨架与 pygame 一致
- **死循环会卡住页面**，刷新即可，代码草稿不会丢
- **画布是 400×300**，坐标范围固定
- 移动端可用，但编程体验最好还是在电脑上
